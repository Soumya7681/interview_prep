# Full-Stack Developer Interview Prep Book

A structured, multi-file preparation guide for the **React.js / Node.js Full-Stack Developer** role at top tech companies.

Every concept follows the same pattern:

> **Definition → Explanation → Code Example → Real-World Use → Likely Interview Questions**

---

## 🎯 How to Use

### One week out
- Master **JavaScript**, **React**, and **Node.js**.
- Type out every code example by hand — don't copy-paste.

### Two days out
- Read **Express/NestJS** and **MongoDB**.
- Walk through **Machine Coding** exercises with a timer.

### One day out
- Skim **System Design**.
- Practice the **HR / Behavioral** self-introduction out loud, recorded.

### The morning of
- Read **only** the Revision Sheet.
- Pack everything from the Appendix.

---

> **Final note:** You already have hands-on production exposure with the exact stack companies want — MERN, NestJS, AWS S3, Swagger. Lead with **specific stories and numbers** from your work. Textbook answers everyone has; *your projects* are your differentiator.

**Good luck — go own it.**
